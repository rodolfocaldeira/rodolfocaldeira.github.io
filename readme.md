rodolfocaldeira.com
===================

My personal website: [rodolfocaldeira.com](https://rodolfocaldeira.com).

This repo is the GitHub *user site*, so the custom domain also covers every
other repo of mine that has Pages turned on, served at `rodolfocaldeira.com/<repo>/`
(for example `/blog/` and `/expenses-calculator/`).

Deploys: pushing to `master` publishes `public/` via `.github/workflows/pages.yml`.
